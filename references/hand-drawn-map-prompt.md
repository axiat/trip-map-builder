# 手绘旅行地图 · 固化生成 prompt

> 同步自 `~/Qbsidian/Travel/旅行规划流程.md` Part 5。两边内容必须一致，
> 改任何一边时同步另一边。

每次使用时填写【旅行资料】部分，其余规则原样保留：

````text
请根据以下旅行资料，生成一张以真实地理位置为基础的可爱手绘旅行地图。画面兼顾景物插画、路线识别和简洁的行程查阅。

【旅行资料｜每次填写】

目的地：
旅行日期：填写年份、月份和日期。
逐日行程：
第1天：日期｜景点顺序｜住宿地点｜可选项目
第2天：
……按实际天数填写，也可直接粘贴完整攻略。

出发地、同行描述：可留空，用于副标题。
参考资料：可留空，可附地图链接、地图截图、景点定位或参考画风。
特别要求：可留空，例如必须保留的景点、需要上图的交通时刻、路线配色。

【一、地理位置】

先查阅可靠地图或使用所附地图，核对景点、市区、机场、车站和住宿地点的位置，再安排画面。

地图默认上北下南。各地点的相对方位、远近关系和交通连接应有地图依据。先确定地点位置，再绘制景物插画；景点图标可以适度放大，必要时用短引线连接实际位置。

相距较远的地点之间允许留白，也可少量绘制当地真实的山林、平原或水域。保持实际空间关系优先于填满画面。

景点密集时可以增加单独的局部放大图，并注明放大区域。河流走向、湖泊位置和道路连接依地图绘制。游览路线与实际道路采用不同画法。

同一地点只绘制一次。多天经过或游览同一地点时，在该地点标注多个日期。

角落小字注明"旅行示意图"。指北针与实际方向一致；只有采用统一比例时才绘制比例尺。

若关键地点无法核实，先请求补充地图截图或定位，再生成图片。

【二、画风】

固定为3:4竖版。

采用可爱的蜡笔／彩铅手绘风格，奶白色纸张质感底，线条圆润，保留细腻的颗粒笔触。色彩清新明快，主色根据当地景观和旅行季节选择。

山林、建筑、湖泊、动物和食物绘制成容易辨认的微缩插画。建筑和自然景观保留主要外形特征。

季节和节日元素少量融入景物，例如秋叶、积雪或月亮。具体天气和气温仅使用已确认的信息。

全图使用简体中文。标题有手写感，地名、日期和行程文字清晰可读，适合手机查看和打印。

【三、版式】

顶部：
大标题采用"目的地＋旅行主题"；未提供主题时使用"目的地旅行地图"。
副标题写日期、出发地及已提供的同行描述，缺失字段直接省略。

主体地图：
占画面约三分之二，是全图的主要内容。
景点直接绘制在对应位置，旁边标注地名。住宿地点使用小房屋或床铺图标，注明入住日期。
每日路线用虚线和小箭头连接，方向与实际行程一致。
默认按天分色；若特别要求统一颜色，则全程使用棕色路线。
日期使用简洁的小纸签，例如"9/24"，贴近当天路线起点。地图布局按地理位置组织，日期标签负责区分每天的活动。
可选景点标注"可选"，与确定行程区分。

特色插画带：
位于地图下方，保留3—4个有资料依据的当地美食小插画，仅标名称。
必要的小贴士最多3项，用图标＋短词表达，例如"保暖衣物、雨衣、登山杖"。
未提供且无法核实的内容直接省略。

底部行程概览：
按实际天数排列简洁小格。
每格仅保留日期、一行主要活动、一行住宿或返程信息。
例如：
9/24
抵达 · 市区散步
宿：市区

地图已列出的完整景点清单不再重复抄入概览。

【四、信息密度】

文字限于标题、日期、地名、路线、住宿、必要交通信息和少量实用提示。

不增加抒情口号、宣传语、装饰性段落或重复的"必打卡"清单。节日彩蛋和小装饰以图形呈现。

景点之间保留明显空白，文字与图标之间保持间距。内容较多时优先缩减说明文字和重复信息，保证地名与日期的字号。

【五、生成前检查】

核对地点相对位置、路线箭头方向、日期对应、住宿日期和中文地名。
地图与底部概览保持一致。
确认行程与可选项目分别标示。
所有上图信息均来自旅行资料或已核实的来源。

资料充分时直接绘制；仅在关键地理位置或行程存在无法解决的歧义时提问。
````
